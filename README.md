# 小六壬占卜程序

基于传统小六壬法开发的桌面占卜工具，支持**透明推算过程展示**，每一步月起始、日走位、时落位都清晰可见。

---

## ✨ 功能特色

- 🔮 **透明推算**：分三步展示完整占卜过程（月起始 → 日走位 → 时落位）
- 📖 **完整卦象解读**：六神均有详细解释，涵盖事业、财运、感情、健康、失物、出行、官非七个维度
- 🕐 **实时时辰**：自动获取当前时间并显示对应时辰，参与占卜计算
- 🎨 **图形界面**：基于 tkinter 的友好 GUI，支持 Windows / macOS / Linux
- 🎲 **两种占卜模式**：时间占卜（精确）和随机占卜（快速）
- ☯ **卦象符号**：每个结果配有对应卦象符号

## 🚀 快速开始

### 环境要求

- Python 3.6+
- tkinter（Python 自带，无需额外安装）

### 启动方式

**方法一：直接运行（推荐）**

```bash
# 透明推算版（推荐）
python gui_divination_transparent.py

# 或增强版
python gui_divination_enhanced.py
```

**方法二：Windows 双击启动**

双击 `启动透明推算版.bat` 即可。

## 📖 使用说明

1. 在输入框中输入要占卜的问题，例如：
   - `近期运势如何？`
   - `这个项目能成功吗？`
   - `明天出行是否顺利？`

2. 点击**「开始占卜」**按钮，程序根据当前精确时间进行推算
   - 也可点击**「随机占卜」**进行快速占卜

3. 在**「推算过程」**标签页中查看三步推算详情：
   ```
   【第一步：月起始】
   农历6月 → 【空亡】

   【第二步：日走位】
   从【空亡】开始，走2步 → 【大安】

   【第三步：时落位】
   从【大安】加【空亡】（21时）→ 【空亡】
   ```

4. 在**「总体判断」**标签页中查看各方面详细解读

5. 点击**「查看详解」**查看完整卦象解读

## 🔮 小六壬占卜原理

### 六神速查

| 六神 | 五行 | 卦象 | 含义 | 数字 |
|------|------|------|------|------|
| 大安 | 木 | ☳ | 安稳、吉祥、守成 | 1、5、7 |
| 留连 | 土 | ☷ | 拖延、纠缠、反复 | 2、8、10 |
| 速喜 | 火 | ☲ | 喜庆、快速、成功 | 3、6、9 |
| 赤口 | 金 | ☱ | 口舌、凶险、争执 | 4、7、10 |
| 小吉 | 水 | ☵ | 和合、顺利、喜悦 | 1、5、7 |
| 空亡 | 土 | ☶ | 虚空、失败、消散 | 3、6、9 |

### 推算步骤

**第一步：月起始**
```
正月→大安   二月→留连   三月→速喜
四月→赤口   五月→小吉   六月→空亡
（七月起重头循环）
```

**第二步：日走位**
> 从月起始位置开始，按日期数顺推，走 N-1 步（N为日期）

**第三步：时落位**
> 从日走位结果开始，按时辰对应的六神位置相加，最终落位即为占卜结果

## 🛠️ 开发说明

### 核心类结构

```
XiaoLiuRen               # 占卜逻辑类
├── get_month_position()  # 月起始
├── get_day_position()    # 日走位
├── get_hour_position()   # 时落位
├── divine_with_steps()   # 完整分步占卜
└── random_divine()       # 随机占卜

DivinationGUI             # GUI界面类
├── setup_ui()            # 构建界面
├── perform_divination()  # 执行占卜
├── display_steps()       # 展示推算过程
└── show_detail()         # 显示详细解读
```

### 本地开发

```bash

cd xiao-liu-ren
python gui_divination_transparent.py
```
